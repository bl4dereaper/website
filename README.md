# Shrieve Industries — Website

The marketing site for [Shrieve Industries](https://www.shrieveindustries.com),
a cultural heritage imaging software company.

## What lives here

- `index.html` — single-page site (hero, Kairo, audience, approach, what's next, contact)
- `styles.css` — museum-gallery aesthetic: warm near-black, parchment, gold, spectral-band motif
- `CNAME` — points this repo at `www.shrieveindustries.com`

Static HTML/CSS/JS. No build step, no dependencies. GitHub Pages serves it
directly from the repo root.

## Products

- **Kairo** — end-to-end multispectral imaging software for historical
  artifacts (first release). See <https://github.com/bl4dereaper/KAIRO>.

## Editing

Edit the HTML/CSS, commit to the default branch, and GitHub Pages rebuilds
automatically.
